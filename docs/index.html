Apple HIG for GPUI macOS Sonoma & Sequoia

A comprehensive, production-grade implementation of Apple Human Interface Guidelines for desktop applications written in Rust with GPUI. Provides pixel-accurate native controls, semantic Light and Dark appearances, Apple system typography, and full keyboard accessibility.

Human Interface Guidelines Compliance: Every component in this library strictly adheres to Apple macOS metrics: 6pt control corner radii, 10pt card corner radii, 52pt toolbar height with 78pt traffic light clearance, standard system accent colors, and San Francisco typography hierarchy.
Cargo.toml Setup 
[dependencies]
gpui-apple-hig = { git = "https://github.com/lavs9/HIG-GPUI", branch = "main" }
gpui-kit = "0.1"
Quickstart: Initializing Apple Theme 
use gpui_apple_hig::{apply_apple_theme, AppleAppearance, MacAccentColor, MacSwitch, MacButton};
use gpui::*;

fn main() {
    App::new().run(|cx: &mut AppContext| {
        // Apply native Apple palette and typography
        apply_apple_theme(cx, AppleAppearance::System, MacAccentColor::Blue);
        
        // Open native window with Apple HIG styling...
    });
}

HIG Guideline: Use a switch to toggle between two mutually exclusive states that take effect immediately without requiring a Save or Apply button. Use a descriptive label beside the switch that clarifies what will happen when toggled on.
Rust GPUI Implementation 
use gpui_apple_hig::{MacSwitch, MacSwitchSize};

// Standard Regular Switch
MacSwitch::new("auto-sync-switch", self.auto_sync_enabled)
    .size(MacSwitchSize::Regular)
    .on_click(cx.listener(|this, _event, cx| {
        this.auto_sync_enabled = !this.auto_sync_enabled;
        cx.notify();
    }))

// Mini Switch for compact table cells or inspectors
MacSwitch::new("mini-hdr-switch", self.hdr_preview)
    .size(MacSwitchSize::Mini)
