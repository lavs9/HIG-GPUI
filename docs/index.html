Apple HIG for GPUI macOS Sonoma & Sequoia

Production-ready implementation of Apple Human Interface Guidelines for desktop applications written in Rust with GPUI. Explore live interactive playgrounds with prop controls, visual state galleries, and copyable Rust GPUI code.

Native GPUI Showcase: You can also run the full interactive desktop application natively via GPU: cargo run --example showcase
Cargo.toml Setup 
[dependencies]
gpui-apple-hig = { git = "https://github.com/lavs9/HIG-GPUI", branch = "main" }
gpui-kit = "0.1"
