Apple HIG Materials Guidelines & Accessibility Best Practices
  • Establish Visual Hierarchy: Use thicker materials (like Thick or UltraThick) for floating cards, dialogs, and sheets so they visually detach from underlying busy content. Reserve Thin for sidebars to maintain an open workspace feel.
  • Vibrancy Pairing: Always render text using Apple semantic tokens (apple_colors.label, apple_colors.secondary_label) which dynamically blend into the material. Never use quaternary or low-contrast text on Ultra-Thin materials.
  • Avoid Material Stacking: Do not stack multiple translucent materials directly on top of each other; the compounded blurs create visual mud and unpredictable color shifts.
  • Accessibility (Reduce Transparency): Respect the macOS system setting in System Settings > Accessibility > Display > Reduce Transparency. When enabled, MacMaterial::reduce_transparency(true) automatically switches to high-contrast opaque surfaces (#F2F2F7 light, #242426 dark).
  • Inactive Window State: When a window loses focus, macOS automatically decreases vibrancy saturation and increases opacity so the active window commands the user's attention.
